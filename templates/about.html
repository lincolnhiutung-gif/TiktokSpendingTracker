About this project

What it's for

This site tests the hypothesis that young people aged 16 to 24 are influenced by TikTok trends to buy products they wouldn't otherwise have bought. Anyone can add a purchase, browse and filter the data, fix or remove an entry, and see the results as charts.

Universal Design

  • Works on phones, tablets and laptops.
  • Every chart has a text summary and a data table, so the information doesn't rely on seeing the image.
  • High-contrast colours, a dark theme, and clear keyboard focus outlines.
  • A “Skip to main content” link and proper headings for screen readers and keyboard users.
  • No JavaScript is needed, so the site works on older devices and with scripts turned off.

How it's built

Python with Flask serves the pages, SQLite stores the data in three linked tables (respondents, purchases and categories), and Matplotlib draws the charts.
